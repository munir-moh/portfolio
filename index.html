About Me

Who I am & what I do

I'm Munir Mohammed, a Computer Science student and Full Stack Developer who builds complete, end-to-end web applications — from the database and server logic all the way to the interface users interact with.

On the backend, I specialise in Python-based frameworks — Flask and FastAPI — building APIs, data-driven tools, and automation systems. I work with PostgreSQL and SQLite for data persistence and structure my projects around clean, reliable server-side architecture.

On the frontend, I bring those backends to life with HTML, CSS, Vanilla JavaScript, and React — crafting responsive, user-friendly interfaces that connect seamlessly to the systems behind them.

I use tools like Git, Ngrok, and VS Code in my daily workflow and I'm always pushing to grow across the full stack. If something is broken, inefficient, or missing — I want to build the fix, from the first line of code to the final pixel.
