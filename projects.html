01
Football Booking System
A simple system for booking football fields without stress and managing reservations.
▼
Problem
  • Users had difficulty booking football field due to a lack of a centralized system.
  • Existing methods were time-consuming, resource-intensive, and error-prone.
  • There was no efficient way to manage and track reservations.
  • Users lacked transparency in checking field availability.
Solution

I built a football booking system that allows users to easily view available time-slot, make reservations, and manage their bookings. The system provides a user-friendly interface for both customers and administrator, streamlining the booking process and improving overall efficiency.

Tech Stack
Python Flask SQLite SQLAlchemy
Challenges Faced
  • Implementing the payment system
  • The challenge was tackled by integrating a manual payment solution (with reference number for admin to validate payments) while maintaining a good user experience.

Barbing Booking System
A simple app for booking and managing barbing appointments with a clean, intuitive interface.
▼
Problem
  • Users had difficulty booking and managing barbing appointments.
  • Existing method was time-consuming,tiring and inefficient.
Solution

I built a simple barbing booking app that allows users to easily book and manage their appointments with stylists of their choice. Tech Stack
Python Flask SQLAlchemy SQLite
Challenges Faced
